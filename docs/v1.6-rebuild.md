# v1.6 整合记录

基底：`30baefd`（v1.6）。参考提交：`0b4a1cb`（v1.7.0）。后续整体可靠性修复、架构和测试以 [architecture.md](architecture.md) 为准。

## 取舍

- 恢复 v1.6 首次访问的完整问候流程与英文文案；沿用首页布局，不增加时钟。
- 保留跳过、减少动画支持，防止重复回车触发多次退场；等待首页入场动画完成后再移除动画类。
- 保留颜色自定义，入口改为编辑页关闭按钮左侧的圆点，并同步标题图标颜色；文件夹不再可点击换色。
- 保留配置备份，移至全局设置底部，导入和导出并排；导出当前生效的完整配置，包含未修改过的默认值。
- 移植请求超时、位置绑定天气缓存、定位权限、搜索引擎回退、即时保存、拖拽索引修复、键盘操作、主题提前初始化。
- 沿用简洁的温度/体感/高低温显示，不引入 v1.7 新增的天气状况文字。
- 导入前检查主题、语言、分组、链接、搜索引擎和位置数据；拒绝不合法的链接协议。导出默认不含 API Key，可在导出对话框中明确勾选包含明文 Key；不含 Key 的文件导入时保留已有 Key。
- Key 输入框统一字号、增加隐藏状态字距，提供显示切换；编辑时填入已保存值，保存或关闭设置后恢复隐藏。
- 文件夹图标与分组名称使用水平居中布局。
- 预设搜索引擎图标随项目分发，相同图标不重复替换，不再使用懒加载；单文件 StartPage.html 内嵌图标。
- 欢迎页统一使用 0.75rem 英文 Skip，保留点击留白。
- 修正键盘选择搜索引擎时的事件冒泡，避免选中后再次打开菜单。
- 保留 WOFF2 字体、单文件自动生成及发布包排除本地配置。单文件版内嵌字体、Sortable 和预设图标，不依赖 CDN 初始化。
- 启动时使用统一存储适配层，存储读取或写入被拒绝时使用临时内存配置，避免脚本中断；正常环境仍持久保存。
- 原工作区的网址识别修改单独保存在 Git stash，未移植其将裸三级域名识别为搜索词的规则。
