# v1.6 整合记录

基底：`30baefd`（v1.6）。参考提交：`0b4a1cb`（v1.7.0）。

## 取舍

- 恢复 v1.6 首次访问的完整问候流程与英文文案；沿用首页布局，不增加时钟。
- 保留跳过、减少动画支持，防止重复回车触发多次退场；等待首页入场动画完成后再移除动画类。
- 保留颜色自定义，点击分组标题前的文件夹图标换色，并同步标题图标颜色。
- 保留配置备份，导入和导出并排；主操作与备份区保持 12px 间距。
- 移植请求超时、位置绑定天气缓存、定位权限、搜索引擎回退、即时保存、拖拽索引修复、键盘操作、主题提前初始化。
- 沿用简洁的温度/体感/高低温显示，不引入 v1.7 新增的天气状况文字。
- 导入前检查主题、语言、分组、链接、搜索引擎和位置数据；拒绝不合法的链接协议。导出不含 API Key。
- 修正键盘选择搜索引擎时的事件冒泡，避免选中后再次打开菜单。
- 保留 WOFF2 字体、单文件自动生成及发布包排除本地配置。单文件版仍依赖 CDN。
- 原工作区的网址识别修改单独保存在 Git stash，未移植其将裸三级域名识别为搜索词的规则。

- 首次输入名字后显示个性化问候，完成入场后显示首页；刷新不重复欢迎。
